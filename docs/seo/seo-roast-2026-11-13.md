Use the internal-linking skill at the same commit (`seo/internal-linking/SKILL.md` and `seo/internal-linking/scripts/internal-link-graph.mjs`). Run it after the refresher's approval, or in the same edit as Posts C and D if Nic wants one pass.

Rules to keep from the skill:

- A source post links only to a money page its topic already discusses.
- At least one new link in the first 40% of the body.
- One inline link per target per post. Two to four money links only when the post genuinely matches that many targets.
- Anchors of 3–7 words, saying what the page is. "See the keynote" does not qualify, and it is already used on every post.
- Vary the anchor. The same words no more than three times on the site.
- Dofollow. No `rel="nofollow"` on an internal link.
- The end card can stay as the conversion block. The body links are the fix.
